# Data

The dataset is not stored in this repo (it is large). Download it and place it in this folder.

**Online Retail Dataset** (UK-based online retailer, Dec 2010 to Dec 2011, prices in GBP)

- UCI: search "Online Retail" on https://archive.ics.uci.edu
- Kaggle: search "Online Retail" or "E-Commerce Data" on https://www.kaggle.com

Save the file as one of:
- `data/Online Retail.xlsx` (UCI version)
- `data/data.csv` (Kaggle version)

Expected columns: InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country
